# Remote Commander Tray

Monitor your Desktop Commander Remote connection from the Windows system tray. Remote Commander Tray shows the connection status and restarts the remote agent if it crashes. Use the tray menu to restart or stop the connection yourself.

Requires a separately installed Node.js 22.12 or newer, the official Desktop Commander
CLI, and a Desktop Commander Remote account. This independent companion is not an
official Desktop Commander product. The interface is in English.
Windows 10 version 2004 or later, or Windows 11, is required.

- See Online, Connecting, Authentication required, Offline, and Stopped states.
- Restart or stop the managed remote connection from the tray menu.
- Recover from agent crashes with bounded retry delays.
- Choose whether the tray starts when you sign in to Windows.
- Open local logs and copy a sanitized diagnostic summary.

The companion is free and open source. The remote service is separate and its own
account requirements, usage limits and terms apply. Authentication and remote access
are handled by the official CLI. The tray does not provide a separate security
sandbox for remote commands. Install prerequisites before launching the app; the
Store version does not automatically download them.
